## Fluffy flip🎀

Fluffy flip is a fun and engaging memory card-flipping game where players need to match pairs of cards. The game features cute and colorful cards, with a pink and white theme, offering a delightful experience for all ages. It's perfect for testing your memory while having fun!

## Project Description

This is a simple yet addictive card-matching game developed using HTML, CSS, and JavaScript. The game is responsive and works across different screen sizes, from mobile to desktop. The goal is to flip two cards at a time and match them. The game keeps track of the moves made and the time taken to complete the game, providing feedback on your performance.

## Features

Memory Matching: Match pairs of cards to win.

Timer & Move Counter: Track your time and number of moves.

Responsive Design: Optimized for both mobile and desktop.

Cute Design: Pink and white color scheme with playful icons.

Sound Effects: Fun sound effects for flipping and matching cards.

Game Reset: Start a new game with a simple click of a button.

## How to Play

Start the Game: Click the "Start Game" button to begin.

Flip Cards: Click on a card to flip it. Try to match two cards that have the same image.

Match All Cards: Continue flipping cards until all pairs are matched.

Track Progress: Your number of moves and time are shown at the top of the screen.

Congratulations: Once all pairs are matched, a congratulatory message will appear with your score.

## How to Play:

Click on a card to flip it over.

Try to find its matching pair by flipping another card.

If they match, they stay flipped. If they don’t match, they will flip back after a short delay.

Keep track of your moves and time. Your score will be calculated based on the number of moves and time taken.

## Technologies Used

HTML5 for structuring the page.

CSS3 for styling and responsiveness.

JavaScript for game logic and interactivity.

## Game Features

Difficulty Levels: Choose between easy or hard difficulty for more challenging gameplay.

Timer: A timer keeps track of how long it takes to match all pairs.

Moves Counter: The number of moves is displayed, encouraging you to play better.
